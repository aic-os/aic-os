# 📖 Глоссарий AIC-OS

| Термин | Значение |
|---|---|
| **AIC** | AI Coin — нативная монета проекта |
| **aCOIN** | Обёрнутый актив (aBTC, aETH, aUSDT) |
| **AIC-ID** | Человекочитаемый адрес `@name` |
| **AIC Chain** | Собственный блокчейн проекта |
| **ChainTraits** | Rust-трейт: единый интерфейс к разным сетям |
| **ProviderFactory** | Слой, создающий RPC-клиент для конкретной сети |
| **DPoS** | Delegated Proof of Stake — финализация через мастер-ноды |
| **RandomX** | CPU-friendly PoW-алгоритм (Monero-стиль) |
| **Schnorr** | Быстрая подпись (Bitcoin Taproot) |
| **ML-DSA-65** | Постквантовая подпись (Dilithium), стандарт NIST |
| **Proof of Luck** | Лотерея для легких нод (не майнинг) |
| **Dead Man's Switch** | Механизм наследства: нет активности N мес → передача |
| **Matrix** | Open-source протокол для мессенджера |
| **WireGuard** | Современный VPN-протокол |
| **DKG** | Distributed Key Generation — распределённый ключ моста |
